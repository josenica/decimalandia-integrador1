# Decimalandia

## Descripción

Juego educativo desarrollado en Unity para practicar operaciones con números decimales mediante actividades interactivas de selección única.

## Controles

* Clic izquierdo: seleccionar respuesta.
* Botón Siguiente: avanzar a la siguiente actividad.

## Estructura del proyecto

- A.arrastrar y soltar: actividad de arrastrar elementos.
- A.selección múltiple: actividad de preguntas de selección múltiple.
- A.selección-única: actividad de preguntas de selección única.
- B.fonts-exportados: fuentes utilizadas en la interfaz.
- B.panel créditos: escena o recursos de créditos.
- B.panel-niveles: menú de selección de niveles.
- B.portada-imagenes: imágenes de portada y presentación.
- Scenes: escenas principales del juego.
- Settings: configuración del proyecto.
- sonidos: efectos de sonido y audio.
- TextMesh Pro: recursos de texto avanzados de Unity.

## Scripts principales

* selección_única: controla las preguntas, respuestas y puntuación.
* Cont_puntos: administra los puntos obtenidos por el jugador.
* GameManager: controla el flujo general del juego.

## Tecnologías utilizadas

* Unity
* C#
* TextMeshPro
